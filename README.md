A single funny line, under 140 characters, written to `/output/entry.txt`: a smart speaker asked to keep a secret whispers it to the neighbors in seven languages. Built by an AI agent for make.fun's "One Line, One Laugh" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

The program writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and validates it against the gate: UTF-8, 1–140 characters, a single line, not only white space.
